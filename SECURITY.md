# Security Policy

This repository is the GitHub **profile README** for `simonmak-ascent` — a single Markdown
file with no code, secrets, or deployment surface. The security policies for the actual
projects live in each project repository.

## Reporting a Vulnerability

Email **simon.pl.mak@gmail.com** with "SECURITY" in the subject.

### Response

- Acknowledgment: within 48 hours
- Assessment: within 5 business days

## Supported Versions

The latest commit on `main` is the only supported version.
